# Themed Panel Art Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the History, Council, and Events modal panels real painted background art per theme (3 panels x 3 themes), reusing the existing theme-switching machinery `CosmeticsPanelController` already has for the scene background.

**Architecture:** Three new `Sprite[3]` fields on `CosmeticsPanelController` (index-aligned to the existing `Themes` array, exactly like `backgroundSprites`), applied in `ApplyTheme` via the existing `GetBackgroundSprite` fallback lookup unmodified. `CoreLoopSceneBuilder` gains a generalized `LoadThemedSprite`/`LoadThemedSprites` pair (replacing `LoadBackgroundSprite`/`LoadBackgroundSprites`) that also loads the 8 committed panel art files; the one intentionally-missing file (`event_event.png`) resolves through the existing null-sprite-falls-back-to-index-0 mechanism with no special-case code.

**Tech Stack:** Unity 6000.3.23f1, C#, NUnit PlayMode tests, Unity batch-mode CLI for scene rebuild/verify/test runs.

## Global Constraints

- 3 panels only (History, Council, Events) -- Customize panel art is explicitly out of scope this pass and stays untouched (fixed navy, no sprite field, no art).
- `event_event.png` (Events panel, Harvest Hall theme) is deliberately not committed -- `eventPanelSprites[2]` stays null and resolves via the existing `GetBackgroundSprite` fallback to `eventPanelSprites[0]` (Default). No special-case code for this -- it is the same fallback path a missing/corrupt file has always taken.
- Art files already committed at `Assets/Art/PanelArt/<panel>_<themeid-lowercase>.png` (8 files: `history_default.png`, `history_council.png`, `history_event.png`, `council_default.png`, `council_council.png`, `council_event.png`, `event_default.png`, `event_council.png`), all 1024x1792 -- see `docs/superpowers/specs/2026-09-06-panel-art-design.md`.
- `Verify()`'s new checks assert array presence and length (== 3) only, NOT per-element non-null -- a per-element check would fail on the deliberately-missing `eventPanelSprites[2]`.
- `LoadRulerPortraits`/`LoadPortraitSprite` are a different asset shape (15 mood x loyalty images) and are explicitly left alone -- do not fold them into `LoadThemedSprites`.

```csharp
        private static Sprite LoadThemedSprite(string path)
        {
            var importer = AssetImporter.GetAtPath(path) as TextureImporter;
            if (importer != null && importer.textureType != TextureImporterType.Sprite)
            {
                importer.textureType = TextureImporterType.Sprite;
                importer.SaveAndReimport();
            }
            return AssetDatabase.LoadAssetAtPath<Sprite>(path);
        }

        // Order matches the existing Themes array exactly (Default, Council,
        // Event) -- CosmeticsPanelController.GetBackgroundSprite indexes into
        // this array using the same Themes array as its lookup key. Generic
        // over folder/fileNamePrefix so it serves the scene background AND
        // all three panel-art sets (history/council/event) -- see
        // docs/superpowers/specs/2026-09-06-panel-art-design.md's Loader
        // consolidation section. A missing file (event_event.png is
        // deliberately not committed -- see that spec's Scope Decisions) logs
        // an error here and leaves that index null; CosmeticsPanelController's
        // existing GetBackgroundSprite falls back to index 0 for it.
        private static Sprite[] LoadThemedSprites(string folder, string fileNamePrefix)
        {
            string[] themeIds = { "default", "council", "event" };
            var sprites = new Sprite[3];
            for (int i = 0; i < themeIds.Length; i++)
            {
                sprites[i] = LoadThemedSprite($"{folder}/{fileNamePrefix}_{themeIds[i]}.png");
            }
            for (int i = 0; i < sprites.Length; i++)
            {
                if (sprites[i] == null)
                {
                    Debug.LogError($"CoreLoopSceneBuilder.LoadThemedSprites: failed to load sprite at index {i} for {fileNamePrefix} in {folder}");
                }
            }
            return sprites;
        }
```
